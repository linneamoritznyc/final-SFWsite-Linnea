# Internal development files

Not part of the production site. Not linked from navigation. Reference only.

## Reference pages

- **design-system.html** — visual catalogue of every component, token and pattern in `css/site.css`.
- **motion.html** — 16 motion studies on brightfield microscopy footage. Uses `motion.css` and `motion.js` (both in this folder). Delete all three once a direction is chosen; fold the winner into `site.css`/`site.js`.
- **community-mockup.html** — early standalone prototype of the community page, superseded by the production `community.html`.

## Supporting files

- **motion.css** — stylesheet for the motion studies page only.
- **motion.js** — LUT-based luminance stretching for microscopy footage. Pairs with `motion.html`.
- **open-sources-brief.md** — instructions for fetching sample assets from open-license sources (NIH BioArt, CDC PHIL, USDA, BHL, etc.).

## Asset delivery spec

- **asset-delivery/community/** — expected filenames, formats and size limits for community page media assets not yet delivered by the Foundation. Includes placeholder directories for `img/` and `video/`.
