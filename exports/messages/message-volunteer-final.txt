Hi! The Volunteer page of new.soilfoodweb.com is ready: Linnea has approved its images and the 21 role icons. Please add it to the Drive folder for Stephanie.

WHAT TO DO
1. In the folder "SFW website images for Stephanie", create the subfolder "05 Volunteer" and put the 27 files below in it (6 photos and 21 icons).
2. Download each file from its "File" link (public GitHub links). Photos are JPG, under 300 KB, EXIF removed, already cropped to the exact shape of their slot on the WordPress page. Icons are 512 x 512 transparent PNG in Food Web Green (#156826), shown on the page at 48 x 48 px. Name each file exactly as shown after "Save as", so the numbers keep them in page order.
3. In "05 Volunteer", add a Google Sheet "Volunteer image list", columns: #, Where on the page (the "Jump to" link), Section, Slot, File name, Alt text, Caption, Size. One row per file, in the order below.
4. Rename the subfolder to "05 Volunteer (FINAL)" so Stephanie knows this page is ready to upload.
5. Make sure Stephanie still has access to the main folder, then give Linnea the link to "05 Volunteer (FINAL)".

HOW STEPHANIE USES IT
Each "Jump to" link opens the WordPress page and scrolls to the section (the new sections only work once she has built them, as on the preview: https://finalsite-git-final-images-v2-linneamoritznycs-projects.vercel.app/volunteer/). "Slot" says which image it is: hero = the big picture at the top; card 1, 2 = the "Start in the next ten minutes" cards, left to right (card title in brackets); image 1 = the picture next to the text; icon 1 to 21 = the role cards in "Pick the way you want to help", left to right, row by row (card title in brackets). She uploads the file into that slot, pastes the alt text into the image's Alternative Text field, and the caption (if there is one) into the caption field. The icons are decorative: their alt text stays empty, because the card title next to each icon says the same thing. The SVG versions are in the repo at img/icons/volunteer/ if WordPress takes SVG.

The third "Start in the next ten minutes" card (Show us your soil) has no photo: the photo Linnea chose for it (R5A_4016) is already the Permaculture Design Certification course card.
