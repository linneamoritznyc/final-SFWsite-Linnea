Hi! The Home page of new.soilfoodweb.com is now final: Linnea has approved every image on it. Please add it to the Drive folder for Stephanie.

WHAT TO DO
1. In the folder "SFW website images for Stephanie", replace everything in the subfolder "01 Home" with the 24 images below (some images changed since the last list, so start the subfolder fresh rather than updating it). If the folder doesn't exist yet, create it, with "01 Home" inside.
2. Download each image from its "File" link (public GitHub links; JPG, under 300 KB, EXIF removed, already cropped to the exact shape of its slot on the WordPress page). Name each file exactly as shown after "Save as", so the numbers keep them in page order.
3. In "01 Home", replace the Google Sheet "Home image list" with a new one, columns: #, Where on the page (the "Jump to" link), Section, Slot, File name, Alt text, Caption, Size. One row per image, in the order below.
4. Rename the subfolder to "01 Home (FINAL)" so Stephanie knows this page is approved and ready to upload.
5. Make sure Stephanie still has access to the main folder, then give Linnea the link to "01 Home (FINAL)".

HOW STEPHANIE USES IT
Each "Jump to" link opens the WordPress page and scrolls straight to the section. Inside that section, "Slot" says which image it is: hero = the big picture at the top; tile 1, 2, 3... and card 1, 2, 3... are counted left to right (in the program carousel, scroll right for cards 5 to 12); banner = the full-width photo behind the section text; side image = the picture next to the text. The name in brackets is the card's or tile's title on the page. She uploads the file into that slot, pastes the alt text into the image's Alternative Text field, and the caption (if there is one) into the caption field.

The "Original" line, where there is one, is the full-size source, in case a bigger version is ever needed. You don't need to copy it.
