# Final image decisions, 6 October 2026

These are the images that are live on https://finalsite-tau.vercel.app, which is built from the main branch. Linnea approved every row on 5 and 6 October 2026. This file is for updating the website asset log spreadsheet.

How to read the columns:

- **Source file** is the original file name in Google Drive or in this repo.
- **Web files** are in `img/new/`. Each image has a WebP and a JPG at 1600 px and at 800 px wide, each under 300 KB, with EXIF removed. Originals are in `img/new-2026-10/`.
- **Rights**: the Brevity Media shoot (R5A files) is owned by the Soil Food Web Foundation. Linnea confirmed this on 4 October. The microbe library photos are student and graduate micrographs, credited by name. The restoration diagrams have a publication licence PDF in the same Drive folder.
